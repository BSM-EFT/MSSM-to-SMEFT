# MSSM to 2HDM-EFT matching results in Mathmatica format
This directory contains the results of the MSSM to 2HDM-EFT matching in Mathematica format:

- `MSSM-matching-conditions.m` contains the matching conditions expressed through the renormalizable low-energy/SMEFT couplings;
- `MSSM-matching-conditions_not-shifted.m` contains the matching conditions expressed through the renormalizable couplings of the UV/MSSM;
- `2HDM-EFT-Lagrangian_on-shell.m` contains the entire EFT Lagrangian in an on-shell basis;
- `2HDM-EFT-Lagrangian_off-shell.m` contains the entire EFT Lagrangian in an off-shell/Green's basis.
