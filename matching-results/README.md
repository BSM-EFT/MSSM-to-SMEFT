# MSSM-to-SMEFT matching results
This directory contains the results of the MSSM-to-SMEFT matching:

- the directory [Mathematica](Mathematica) contains the matching results in `Mathematica` format (`.m` files);
- the the directory [PDF](PDF) contains the matching results in `pdf` format;
- the file [loop-function_definition.pdf](loop-function_definition.pdf) contains a defintion of all loop functions appearing in the results;
- the file `LoopFunctions.nb` is only used to generate [loop-function_definition.pdf](loop-function_definition.pdf).
