# MSSM-to-SMEFT matching results in Mathmatica format
This directory contains the results of the MSSM-to-SMEFT matching in Mathematica format:

- `MSSM-matching-conditions.m` contains the matching conditions expressed through the renormalizable low-energy/SMEFT couplings (as exported from `MSSM-matching.nb`);
- `MSSM-matching-conditions_detailed.m` contains the matching conditions expressed through the renormalizable low-energy/SMEFT couplings (as exported from `MSSM-matching-detailed.nb`) **\[equivalent to the `MSSM-matching-conditions.m` file\]**;
- `MSSM-matching-conditions_detailed_not-shifted.m` contains the matching conditions expressed through the renormalizable couplings of the UV/MSSM;
- `SMEFT-Lagrangian_on-shell.m` contains the entire EFT Lagrangian in an on-shell basis;
- `SMEFT-Lagrangian_off-shell.m` contains the entire EFT Lagrangian in an off-shell/Green's basis.
